# 🌙 LUNNA — Loja Virtual

## Sobre o projeto

A LUNNA é uma loja virtual desenvolvida como atividade avaliativa da disciplina de Criação de Sites, com o objetivo de colocar em prática os conhecimentos adquiridos em HTML, CSS e JavaScript.

A loja trabalha com produtos de moda, incluindo roupas, calçados, acessórios e itens de beleza.

O projeto busca oferecer uma experiência de navegação simples, organizada e agradável, utilizando uma identidade visual delicada e moderna.

## 🎨 Identidade visual

A identidade visual da LUNNA foi desenvolvida com cores suaves, que representam a proposta da loja.

**Paleta de cores:**
- Creme: `#FFF9F5`
- Rosa claro: `#F3D6DF`
- Rosa principal: `#D982A0`
- Vinho: `#8E4A63`
- Texto escuro: `#30282A`
- Branco: `#FFFFFF`

## 💻 Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e organização visual.
- **JavaScript:** funcionalidades e interações da loja.
- **LocalStorage:** armazenamento local dos dados do carrinho e dos favoritos no navegador.

## 🛍️ Funcionalidades

- Página inicial com banner promocional.
- Navegação por categorias.
- Pesquisa de produtos.
- Catálogo de produtos.
- Filtros e ordenação.
- Visualização individual dos produtos.
- Seleção de tamanho e quantidade.
- Carrinho de compras.
- Cálculo automático do valor da compra.
- Remoção e alteração de quantidade dos produtos.
- Lista de favoritos.
- Formulários de cadastro e login demonstrativos.
- Página de finalização e revisão da compra.
- Newsletter e formulário de contato.
- Layout responsivo para computadores e celulares.

## ▶️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando o Live Server.
4. Navegue pelas páginas e teste as funcionalidades da loja.

## ⚠️ Observações

Este projeto é uma simulação de uma loja virtual desenvolvida para fins educacionais.

Não possui backend, banco de dados ou integração com sistemas de pagamento reais.

Os formulários de cadastro, login e contato são demonstrativos. Os dados do carrinho e dos favoritos são armazenados localmente no navegador.
