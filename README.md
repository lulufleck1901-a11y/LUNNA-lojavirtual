# LUNNA — Loja virtual demonstrativa

Projeto escolar de e-commerce feito com **HTML, CSS e JavaScript**.

## Como executar
1. Baixe ou clone este repositório.
2. Deixe `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra `index.html` no navegador. Também é possível usar a extensão Live Server do VS Code.

## Funcionalidades
- Página inicial com identidade visual da LUNNA.
- Navegação por categorias e busca de produtos.
- Detalhes dos produtos, seleção de cor e tamanho.
- Carrinho com alteração de quantidade, remoção, subtotal e cupom demonstrativo.
- Checkout com formulário de entrega demonstrativo.
- Formas de pagamento simuladas: débito, crédito e Pix.
- Opções de parcelamento de 1 a 6 vezes no crédito, com cálculo ilustrativo.
- Tela de confirmação demonstrativa.
- Favoritos, avaliações ilustrativas, guia de tamanhos, cupons, área de conta, pedidos fictícios, acompanhamento, trocas/devoluções e ajuda.
- Layout adaptável para celular e computador.

## Importante
Este é um protótipo escolar. Não possui backend nem banco de dados. Não processa pagamentos, não cria pedidos reais e não envia nem armazena informações. Não digite dados bancários reais.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Publicação
O projeto pode ser publicado pelo GitHub Pages nas configurações do repositório, selecionando a branch principal e a pasta raiz (`/root`).
